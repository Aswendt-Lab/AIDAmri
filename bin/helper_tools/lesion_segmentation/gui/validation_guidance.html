Validation scans — place guidance, then run

Place cyan lesion seeds inside the stroke and orange avoidance ROIs over ventricles or other unwanted areas. Navigate through slices before running. Guidance applies to both input directions.

Guided selection keeps one continuous 3D region and at most one connected area per slice. Neighbouring areas must touch; it cannot jump to a distant location or across an empty slice. The frozen clean model runs after you click Run when predictions are not yet available; saved examples reuse their baseline prediction. Guidance then selects a continuous region. It cannot add tissue the network missed. No retraining occurs.

Guidance for this dataset

Run saves both native-grid masks, all guidance, avoidance mask, Dice, containment and checkpoint provenance to a new session. Draft marks are also stored in this browser. Restoring marks requires another explicit run. Reference overlays are optional; reference-informed interaction is development, not independent validation. Avoidance-only runs select the largest continuous track and can choose the wrong region; positive seeds are recommended.
